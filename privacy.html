プライバシーポリシー

対象アプリ：KMG YouTube Autopost。運用者：株式会社KMG。連絡先：kumagroup001@gmail.com。

アクセスする情報と目的

Google Driveの対象フォルダ内のファイル名、ファイルID、作成日時、サイズ、ハッシュ等のメタデータと動画データを、投稿対象の選択・重複照合・YouTubeへのアップロードに利用します。OAuthのDrive読み取りスコープはアカウント内のファイルを読み取る権限を含みますが、本アプリは指定された投稿元フォルダと投稿履歴の処理に限定して利用します。

YouTubeの認証チャンネル情報・既存動画情報を、投稿先の確認、重複照合、中断した処理の復旧に利用します。YouTubeアップロード権限を、管理者が承認したKMGの動画投稿に利用します。

公開後の整理を管理者が有効にした場合、追加のDrive権限（画面上は閲覧・編集・作成・削除）を、公開完了・投稿履歴・ハッシュを照合した元動画のゴミ箱移動に使用します。元動画の完全削除は行いません。ゴミ箱の保持期限はGoogleの仕様に従います。

投稿完了通知を有効にした場合、Gmail送信専用権限を使用し、管理者が指定した宛先へ動画タイトル・公開動画URL・種別・公開確認日時を送信します。受信メールを読む権限は要求しません。通知先、送信状態・メール識別子、元動画の移動状態・日時を非公開の投稿履歴に保存します。

保存とサービス提供者

投稿日時、タイトル、DriveファイルID、YouTube動画ID、種別、状態、ハッシュ、映像の知覚指紋、エラー内容をGoogle Driveのアプリ専用非公開領域に保存します。OAuthクライアント情報とリフレッシュトークンはGitHub Actions Secretsに保存し、自動実行の認証に使用します。初回設定時は管理者の端末にも認証情報を保存します。

GitHub Actionsの実行環境は処理に必要な元動画を一時的にダウンロードします。元動画をYouTubeに送信し、設定した公開範囲で配信します。GoogleおよびGitHubを本処理に必要な基盤として使用します。実行ログにはファイル名や識別子、処理状態等が含まれる場合がありますが、アクセストークン・リフレッシュトークン・クライアントシークレットは出力しません。

利用の制限・保管・停止

取得したGoogleユーザーデータを広告目的、第三者への販売、AIモデルの学習には利用しません。Google APIから取得した情報は、Limited Use要件を含むGoogle API Services User Data Policyに従って取り扱います。

二重投稿を防ぐため、投稿履歴は自動投稿の運用中保持します。運用終了時の認証情報・履歴の削除は管理者が実施します。Googleアカウントの接続管理からアクセスを取り消せます。アクセスを取り消しても既にYouTubeへ投稿した動画は自動削除されません。削除が必要な場合は管理者がYouTube Studio等で対応します。

運用者は情報の取扱方法を変更するとき、このページを更新します。問い合わせ・運用停止・データの削除に関する連絡は上記の窓口へお願いします。
